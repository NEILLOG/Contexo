## 目標

正式開發前確認 Avalonia 的中文輸入（注音）、中文字型、深淺色與字級縮放在 Windows 與 macOS 上沒有阻擋性問題。這是採用 Avalonia 的前提：**T15 以後的介面任務要等這個結果**。

## 要做

1. 在 Mac 與 Windows 各執行一次 `poc/ime-avalonia`（步驟見其 README）。
2. 依 README 的 14 個測試項目逐項操作，把結果填進 README 的結果表並提交。
3. 依 README 的判定標準寫下結論：通過／有條件通過／不通過。

POC 程式碼已經寫好，但因為撰寫環境無法連上 NuGet，**尚未實際編譯過**。若第一次執行遇到編譯錯誤，可以交給子代理修正 `poc/ime-avalonia/` 內的程式（只允許修改該資料夾），修正後再由人工測試。
