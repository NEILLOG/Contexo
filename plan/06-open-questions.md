# 06 風險與待決事項

## 待決

- **Embedding 模型選定**：小模型（e5-small / bge-small-zh）與 bge-m3 的中文檢索品質與速度，需以測試集比較。
- **伺服器模式的資料歸屬**：伺服器端資料是每位使用者一份、部門共用，還是公司集中索引共用資料夾？影響權限設計與「清除資料」的範圍。
- **伺服器設定檔格式**：欄位、簽章或加密方式、由誰產生與發放。
- **模型發布方式**：隨安裝檔打包（安裝包變大）或首次啟動下載（企業網路可能擋）。
- **Excel 大表門檻**：「數百格」的實際數值，需以測試集調整。
- **支援的 AI 軟體清單**：第一版除 Claude Desktop 外還要支援哪些。
- **權限**：使用者能讀到的檔案就會進入知識庫，是否需要針對共用資料夾做額外控管。

## 風險

| 風險 | 說明 | 緩解 |
|---|---|---|
| 複雜 Excel 偵測失準 | 一頁多表、多層標題、零散小計列 | 文字仍進向量庫；AI 可先 `describe_table`；低信心交給 AI gateway |
| AI 軟體設定格式改版 | 各家設定檔位置與格式可能變更 | 偵測邏輯獨立模組化，狀態分級顯示，提供「修復」與手動複製 |
| 無法確認 AI 是否真的在用 | 使用者可能在 AI 軟體內停用 | 以 `initialize` 與查詢紀錄作為證據，畫面說明驗證方式 |
| 初次建立太慢 | 文書機 CPU 效能有限 | 小模型 int8、優先近期檔案、可暫停續跑、伺服器模式 |
| 誤刪資料 | 資料夾暫時無法存取被誤判為刪除 | 整個資料夾讀不到不刪；大量消失先詢問 |
| 資料外流疑慮 | 伺服器模式或視覺模型會把內容送出本機 | 預設本機；切換時明確警語；圖片辨識預設關閉 |
| 防毒誤判 | 新發布的 exe 可能被攔截 | 程式碼簽章；避免 PyInstaller 類打包 |
| 修訂、隱藏內容外洩 | Word 已刪除修訂、隱藏工作表等 | 解析時取接受修訂後的版本；隱藏內容的處理方式需決定 |
