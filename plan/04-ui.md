# 04 使用者介面

互動草圖：[ui-mockup.html](ui-mockup.html)

## 原則

- 用「選」取代「填」，用「預設」取代「設定」。使用者不需要輸入路徑、寫 regex 或編輯 JSON。
- 檔案類型以類別呈現（文件、簡報、試算表、PDF、郵件、圖片），不顯示副檔名。
- 自動處理的事情只做輕量提示；會讓 AI 查不到資料的操作才要求確認。
- 所有移除、清除操作都明確告知：**原始檔案不會被刪除**。
- 錯誤原因用白話描述，每個問題只給一個合理的動作。

## 頁面

### 首次啟動精靈

1. 選資料夾：列出常見位置（文件、桌面、OneDrive、下載）並預估檔案數，使用者勾選；可拖放或用系統選擇器加入其他資料夾。「下載」預設不勾。
2. 選檔案類型。
3. 加入 AI 軟體。

顯示首次建立的預估時間，並說明期間可照常使用電腦。

### 資料夾（主畫面）

- 頂部整體進度：進度條、檔案數、預估剩餘時間、目前處理的檔名、暫停按鈕；說明「已處理完的檔案現在就能查詢」。
- 錯誤橫幅：例如資料夾無法存取，附「匯出問題回報」。
- 摘要兼篩選器：全部 / 有問題 / 處理中 / 已完成；資料夾超過約 8 個時顯示搜尋框。
- **清單一行一個資料夾**：名稱、路徑、檔案數、狀態標籤，右側「⋯」選單放次要動作（選擇子資料夾、在檔案總管開啟、立即重新掃描、移除）。
- 依「有問題 → 處理中 → 已完成」排序，已完成群組預設收合。
- **選擇子資料夾以另開視窗呈現**，用勾選樹狀結構取代排除規則；主畫面保持單純清單。
- 加入已包含的子資料夾時提示不需重複加入；加入上層資料夾時提示合併。
- 無法讀取的檔案最多顯示 5 筆，其餘「查看全部」；原因如有密碼保護、正被開啟、檔案損壞、超過大小上限。
- 任何檔案清單或搜尋結果上的右鍵選單：「不要讓 AI 讀這個檔案 / 資料夾」。

### 試試看搜尋

輸入一句話，列出命中的片段、來源位置、相關度與命中方式（語意 / 關鍵字），可開啟原檔或在資料夾中顯示。

### AI 軟體

依 [03 文件](03-retrieval-and-mcp.md) 的狀態分級顯示每個 AI 軟體，提供加入、移除、修復，以及驗證方式說明。

### 設定

- **外觀**
  - 色彩主題：跟隨系統（預設）/ 淺色 / 深色。Avalonia 的 `ThemeVariant.Default` 會自動跟隨 Windows 與 macOS 的深淺色並即時切換。
  - 文字大小：標準 / 大 / 特大，整個視窗一起縮放。
- **運算來源**：只用這台電腦 / 使用公司伺服器。切換時顯示警語並需確認。伺服器設定區只提供匯入設定檔，匯入後顯示唯讀摘要（設定名稱、匯入時間、向量運算端點與模型、向量庫、資料庫、金鑰狀態），附測試連線、重新匯入、移除設定。
- **檔案類型**：類別勾選，圖片預設關閉。
- **行為**：只在電腦閒置時全速處理、開機時自動啟動、關閉視窗時縮小到系統匣、略過超過 N MB 的檔案（下拉選單）。
- **進階**：資料佔用空間、排除清單管理、清除全部資料、開啟記錄檔資料夾、複製 AI 軟體設定內容。

### 關於與問題回報

- 版本號與組建資訊、複製版本資訊。
- 匯出問題回報（見 [05 文件](05-operations.md)）。
- 版本紀錄。

### 狀態列

處理進度、最近的檔案變動（例如「剛剛更新了 3 個檔案」）、目前運算來源、AI 軟體連線狀態、版本號。

## 確認與警語

| 操作 | 方式 |
|---|---|
| 檔案修改、刪除 | 自動處理，狀態列與資料夾列輕量提示 |
| 大量檔案消失 | 暫停刪除並詢問 |
| 移除資料夾 | 確認視窗，強調原始檔案不會被刪除 |
| 切換運算來源 | 列出影響的警語，確認後切換 |
| 清除全部資料 | 需勾選「我了解需要重新建立，可能要數小時」才能按下；可選擇清除後立即重新建立；伺服器模式下只影響本機資料 |

桌面程式的確認一律做在畫面內，不依賴系統對話框。
